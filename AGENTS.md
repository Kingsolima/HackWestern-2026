# Agent instructions

## Entire CLI

Before you run any `entire` command, read [docs/ENTIRE.md](docs/ENTIRE.md). This covers Trails, findings, sessions, checkpoints, search, setup and anything else that uses Entire. Use the commands as ENTIRE.md writes them. Fill in values in `<angle brackets>` from command output, and never guess them.

Never put API keys, TinyFish credentials or other secrets in prompts. Session transcripts are pushed with the code.

## Commits and pull requests

Don't credit any AI as an author. Leave out `Co-Authored-By: Claude ...` and any other AI co-author line in commit messages. Leave out "Generated with Claude Code" and similar footers in PR descriptions.
